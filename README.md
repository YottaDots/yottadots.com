# YottaDots

**Federate your organization. Amplify it with AI.**

YottaDots is an open framework for federated organizations and AI-enabled work.

## Website

https://yottadots.com

## Principles

- Federate
- Align
- Augment
- Evolve

## Open knowledge

- learn from it;
- challenge it;
- contribute to it.
