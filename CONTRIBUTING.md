# Contributing to YottaDots

Thank you for helping improve YottaDots.

YottaDots is an open knowledge project.

## Ways to contribute

You can:

- suggest an improvement;
- propose a pattern;
- improve documentation;
- share an example;
- create a community extension;
- review contributions.

## Contribution process

1. Create an issue or pull request.
2. The contribution is reviewed.
3. Feedback may be requested.
4. Accepted contributions are merged.
5. Contributions may become:
   - Community Extension
   - Candidate Pattern
   - Official Core

## Canonical Core

Changes to the canonical YottaDots core require approval from the core maintainers.

Community extensions do not require inclusion in the canonical core to be valuable.

## Using AI

You are welcome to use AI tools when you contribute. YottaDots is built that
way too (see [How YottaDots uses AI](https://yottadots.github.io/yottadots.com/docs/ai-coworker/how-we-use-ai)).

- **You are responsible** for what you submit, whether or not AI helped. Check
  facts, sources and wording before you submit.
- **Say that you used AI** in the issue or pull request, and briefly how (for
  example "first draft by AI, edited by me").
- **Check the rights.** Do not submit AI output that reproduces material from
  others, such as text from books or articles.
- In commits, you can add a `Co-Authored-By:` line for the AI tool you used.

## Respect

Be constructive.

Challenge ideas, not people.

Share experience openly.

Help others learn.

Better organizations are built together.
