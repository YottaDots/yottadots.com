# How we compare

YottaDots is often asked how it relates to SAFe, the Product Operating Model,
OKRs and other models. Comparisons are only useful if they are fair, so every
comparison on this site follows the same rules.

## Rules

1. **The same questions for every framework.** No framework gets its own
   criteria.
2. **Describe, do not score.** We use *yes / partly / not described*, never
   points out of 5.
3. **Include where others are stronger.** Every comparison has questions that
   YottaDots is likely to lose.
4. **Sources for every claim.** Public sources only, listed on the page. What
   we could not verify is marked **[Needs Evidence]**.
5. **"Not described" means "we did not find it",** not "it is impossible".
   Frameworks evolve, and practitioners often add what the official text
   leaves out.
6. **Anyone can challenge a rating.** Open an issue on GitHub with a source.

## The questions

| # | Question | Why it matters |
|---|---|---|
| 1 | Who decides the **what** (mission, strategy, goals)? | Where direction comes from |
| 2 | Do units help shape the goals, and is that a formal right? | Whether goals are imposed or shaped |
| 3 | What happens to decisions nobody has named? | Whether the centre can quietly grow |
| 4 | Can units opt out of shared services? | Whether shared services must earn their place |
| 5 | Who decides the **how** (delivery method)? | How much the framework prescribes |
| 6 | How detailed is the practical guidance? | How easy it is to start |
| 7 | What is the track record in practice? | How much evidence there is |

Questions 1 to 4 follow from the four YottaDots rules (see
[The YottaDots Method](../method/index.md)), so YottaDots naturally does well
on them. Questions 6 and 7 are there to balance that.

## One-pagers

Each framework also gets a one-page summary in the same format:

1. What it is: three sentences, origin and owner
2. The core idea
3. The seven questions above
4. Strengths
5. Common criticisms, with sources
6. When it fits, and when it does not
7. How it relates to YottaDots: compete, combine or learn
8. Sources and a "last checked" date

The test before publishing: *would a supporter of this framework recognize it?*

decides the how**. Next on the list: Sociocracy 3.0, Team Topologies, Haier
