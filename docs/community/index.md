# YottaDots Community

YottaDots is built in the open.

The method improves when people use it, challenge it and share what they learn.

You can contribute by:

- improving documentation;
- proposing a pattern;
- sharing an example;
- creating a canvas;
- challenging an assumption;
- reviewing contributions;
- translating content;
- sharing practical experience.

You do not need to be a developer.

## Two ways to contribute

### Suggest something

Use the contribution form.

We will help turn your idea into a structured contribution.

### Work directly in GitHub

Experienced contributors can edit pages or submit pull requests directly.

Both routes eventually enter the same review process.
