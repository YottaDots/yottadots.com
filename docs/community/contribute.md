# Contribute to YottaDots

YottaDots grows through contribution.

There are two routes.

---

## Route 1 — Suggest an improvement

You do not need technical knowledge.

Use our GitHub contribution form:

[Suggest an improvement](https://github.com/YottaDots/yottadots.com/issues/new?template=improve-page.yml)

Or propose a new pattern:

[Propose a pattern](https://github.com/YottaDots/yottadots.com/issues/new?template=propose-pattern.yml)

---

## Route 2 — Edit directly

Every documentation page contains an:

**Edit this page**

link.

This creates a proposed change in GitHub.

Changes are reviewed before publication.
