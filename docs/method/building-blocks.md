# Building Blocks

YottaDots will evolve around reusable organizational building blocks.

Initial areas include:

- purpose;
- capabilities;
- decision rights;
- teams;
- platforms;
- governance;
- knowledge;
- AI co-workers;
- feedback loops;
- organizational patterns.

Each building block can evolve independently while remaining connected to the wider system.
