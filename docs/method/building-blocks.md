# Building Blocks

A YottaDots organization is made of a small set of building blocks. Each one
is explained in a principle, rule or pattern.

<small>Status: **proposed (v0.1).** This list follows the four rules of the
method. It will change as the method develops.</small>

| Building block | What it is | Where it is explained |
|---|---|---|
| **Centre** | The board, management team or holding that decides the what | [Rule 1](./index.md#what-makes-it-a-federation), [Federate](./principles/federate.md) |
| **Value streams** | The units that deliver value and decide the how | [Rule 3](./index.md#what-makes-it-a-federation), [Federate](./principles/federate.md) |
| **Goals** | Mission, strategy, OKRs and KPIs: clear, ranked priorities | [Align](./principles/align.md), [Objection round on goals](../patterns/objection-round-on-goals.md) |
| **Proposals and experiments** | Ideas from value streams: proposals the centre must answer, and small experiments that need no approval | [Rule 2](./index.md#what-makes-it-a-federation), [Proposal route](../patterns/proposal-route.md), [Experiment budget](../patterns/experiment-budget.md) |
| **Open decisions** | Decisions the centre still has to make, each with an owner and a visible "decide by" date | [Decisions on time](../patterns/decisions-on-time.md) |
| **The central list** | The short, public list of what the centre decides | [Name what is central](../patterns/name-what-is-central.md) |
| **Guardrails** | The few rules that apply to every value stream | [Guardrails that earn their place](../patterns/guardrails-that-earn-their-place.md) |
| **Shared services** | Services offered to value streams, which they may refuse unless agreed as a guardrail | [Rule 4](./index.md#what-makes-it-a-federation), [Opt-out of shared services](../patterns/opt-out-of-shared-services.md) |
| **Capacity and money** | Teams, suppliers and budgets, allocated to priorities | [Adding capacity is a choice too](../patterns/adding-capacity-is-a-choice.md), [Budgets that do not punish saving](../patterns/budgets-that-do-not-punish-saving.md) |
| **AI co-workers** | AI that does real work, with a named human owner | [Augment](./principles/augment.md), [AI with a human owner](../patterns/ai-with-a-human-owner.md) |
| **Reviews** | Regular moments to keep, change or stop: guardrails, the central list, what was built | [Evolve](./principles/evolve.md), [Usage check](../patterns/usage-check.md) |

Each building block can evolve on its own while staying connected to the
others.
